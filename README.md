# Hi, I'm a Data Engineer 👋

Building scalable data platforms and AI-powered data solutions on **Azure Databricks** and **Snowflake** — with a strong foundation in enterprise BI and application development.

---

### 🚀 What I Do

- **Lakehouse Architecture on Azure Databricks** — Building and orchestrating pipelines with Notebooks & Jobs, and implementing enterprise-grade **Data Governance** using **Unity Catalog** with **RBAC** & **ABAC** access models.
- **Conversational AI on Data** — Built an intelligent chatbot using Databricks **Genie Agent**, and a chat-based data assistant on **Snowflake Cortex**.
- **Snowflake Engineering** — Data processing pipelines, Notebooks, Stored Procedures, and platform administration.
- **Big Data (Cloudera Stack)** — Distributed data processing with **Spark (Scala & Python)**, **Impala**, **Hive**, and ingestion via **Sqoop**.
